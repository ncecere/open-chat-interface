Upgrades run `migrate` (pre-upgrade hook), a rolling update, then `migrate --post`
(post-upgrade hook, after every API and worker pod runs the new release). Run the
preflight first and give Helm enough time for the hooks:
  kubectl -n {{ .Release.Namespace }} run oci-upgrade-check --rm -i --restart=Never \
    --image=<target api image> --overrides='{"spec":{"containers":[{"name":"oci-upgrade-check","image":"<target api image>","command":["node","dist/scripts/upgrade-check.js"],"envFrom":[{"secretRef":{"name":"{{ include "oci.secretName" . }}"}}]}]}}'
  helm upgrade {{ .Release.Name }} ... --timeout 30m
Hook logs: kubectl -n {{ .Release.Namespace }} logs job/{{ include "oci.migrate.name" . }}
           kubectl -n {{ .Release.Namespace }} logs job/{{ include "oci.migratePost.name" . }} --all-containers
